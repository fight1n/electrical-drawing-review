# 标准知识库（示例语料）

本目录存放电气标准条款的纯文本/Markdown 语料，作为检索与审核的知识底座。

- 当前系统的**倒排索引**由 `src/edr/rules/registry.py` 中的规则定义（标准编号 + 关键词）构建，保证零依赖、可离线运行。
- 本目录的语料用于：(1) 人工核对条款正文；(2) 后续接入「直接片段召回 / RAG」时作为文本来源（在 `retrieval/` 中扩展一个 `CorpusRetriever` 即可）。

> 生产环境请将贵司采用的标准全文放入此目录（保持 `标准编号.md` 命名），并在 `rules/registry.py` 中补充对应规则即可，无需改动任何核心代码。

已实现示例条目：
- `gb50054.md` — 《低压配电设计规范》GB 50054 相关条款摘录
- `gb4728.md` — 《电气简图用图形符号》GB/T 4728 相关说明
